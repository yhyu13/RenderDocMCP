Radiance Cascades 交互式可视化

配套《逆向 Radiance Cascades》一文。三个概念：空间密度（探针多密）、角密度（每个探针打多少条射线）、merge（粗级把远处的光递给细级）。

数据全部对齐 shader 源码：probeSize = 2^(cascade+1)、探针数 = gRes/probeSize、射线长度 = probeSize×8×texelScale。

① 空间密度 vs 角密度（拖动级联看权衡）

光源（面光，产生半影） 遮挡物（墙） 探针（亮度 = 打到的光） 射线（长度 = 本级射线长度） merge 接力箭头

② 五步流水线：这一步到底在干什么

③ 半影假设：近处要空间，远处要角度

一个阴影的半影，靠近遮挡物需要空间分辨率高（探针密），远离遮挡物需要角分辨率高（射线多）。两者成反比，所以级联每上一级：探针 ÷4、射线 ×4。

级联probeSize探针数（空间）每探针射线（角度）射线长度

C0 探针最密、射线最短（只够看贴着的近处）；C5 探针最疏、射线无限长（看最远）。merge 把 C5 看到的远处光一层层递给 C0——这就是「用有限射线模拟无限方向」。

④ 真实 atlas：每层 probe（来自 .rdc）

下面六张是真从 new_rc_split_frame24.rdc 导出的 atlas（1024×512 RGBA32F）。切「距离 α」看探针 trace 到了什么——α 就是 shadeLocal 写的「首击距离」，−1（没打中）显示成深色；切「辐照 RGB」看探针看到了多少光。

下图是上图的中心区域放大 4×。白线框出的每个小块 = 一个探针，块内是它的 probeSize×probeSize 个方向（每个方向一个 texel）。C0 的块最小最密（2×2=4 方向），C5 的块最大最疏（64×64=4096 方向）。
