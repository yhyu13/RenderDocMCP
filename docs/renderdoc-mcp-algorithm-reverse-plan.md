## 二、写作纪律（tech-design-to-zhihu 三条）

1. **说人话**：先比喻后术语。`α`（量尺）、`merge`（接力赛）、`probeSize=2^(c+1)`（半影假设两条腿）第一次出现就落地。
2. **图先行**：每个独立论点一张 PNG，标题即论点，红字钉「不是什么」。
3. **是什么/不是什么**：每段先说什么、紧跟不是什么，正文用对比句。
