树全貌：一条轨迹从 GPU 到文件

根是两个 API 调用；分岔点在"状态流"之后——旧路进 JSON，新路进文件

① 入口

SetFrameEvent(184) → DebugPixel(320,240) 建调试器

→

② 循环

ContinueDebug 反复调用，每批返回若干 ShaderDebugState（step / flags / changes），空批即终点

→

③ 状态流

本文实跑共 12 个状态，内存里是完整对象：变量名 + before/after 值

旧路（capped）：③ → 闸门三层 → 最后 8 状态的名字进 JSON → FreeTrace。中间步的值永久丢失。
新路（debug_trace_export）：③ → 循环走到自然结束 → 每状态全字段序列化 → JSONL 13 行落盘 → 响应只回 path + total_steps → FreeTrace。
