能抄走的六句

① 像素错了，先查 history，不开 shader 跟踪历史给你"谁写的、谁失败的"名单，跟踪只调名单上该调的那个。
② 调最后一个 passing fragment不是随便挑一个——被后来者盖掉的调试是白调。
③ capped 调试只给名字，丢值在打包层RenderDoc 给得出全量；别把工具的省略当成引擎的极限。
④ 大轨迹永远走文件：路径过桥，字节不过桥响应只回 path + 统计，agent 自己切片。1.5 万步塞上下文是炸弹。
⑤ 全轨迹是证据链哪条指令、哪个变量、经几次搬运——capped 版答不了"从哪来的"。
⑥ 验证拿生产捕获，不拿玩具帧12 步轨迹与像素历史逐位对上，才敢说"可用"。
主线一句话：把人类"这个像素为什么错"的调试循环整个搬给 agent，最后一步——完整轨迹——agent 比人拿得更全。切割点在"状态流"与"响应"之间：文件接缝。
